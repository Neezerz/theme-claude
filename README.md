# Circuit Noir — thème Claude

Thème sombre et technologique pour les applications Claude (desktop et mobile) : fond texturé avec grain, grille de points, lignes de balayage et pistes de circuit parcourues de lentes impulsions lumineuses.

Deux versions :

- **violet** (par défaut) : brun profond, pistes cuivrées, accents violets ;
- **cyan** : nuit bleu-acier, accents cyan.

Changer de version (le choix est retenu) :

```
/circuit violet
/circuit cyan
```

## Installation

Dans un terminal Claude Code :

```
/plugin install circuit-noir --marketplace Neezerz/theme-claude
```

Répondre `y` pour ajouter la source, puis choisir la portée *user*.

Depuis un shell :

```
claude plugin install circuit-noir --marketplace Neezerz/theme-claude
```

Dans l'application desktop : cliquer sur **+** à côté de la zone de saisie, puis **Plugins**, **Add marketplace** avec `Neezerz/theme-claude`, puis **Add plugin**.

Dépôt privé : l'ordinateur doit déjà disposer d'un accès git à github.com (clé SSH, ou `gh auth login` puis `gh auth setup-git`).
